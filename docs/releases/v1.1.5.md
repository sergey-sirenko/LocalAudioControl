# Local Audio Control v1.1.5

Добавлены две команды для боковых кнопок мыши:

- Передняя кнопка: `ToggleOutput.exe` переключает два избранных выхода одной кнопкой.
- Задняя кнопка: `NextTrack.exe` отправляет стандартную медиакоманду Windows «Следующий трек».

## Установка и настройка

Запустить `LocalAudioControl-Setup.exe`. Обновление сохраняет избранные устройства, цвета, громкость и остальные настройки.

В Logitech Options+ выбрать «Открыть приложение» и назначить передней боковой кнопке `%LOCALAPPDATA%\Programs\LocalAudioControl\Commands\ToggleOutput.exe`, задней — `%LOCALAPPDATA%\Programs\LocalAudioControl\Commands\NextTrack.exe`. При наличии отдельного профиля RDP повторить назначения в нём.

Переключение читает фактический выход Windows: первое избранное переключается на второе, второе или сторонний выход — на первое. Нужны два разных настроенных избранных. Если целевой выход недоступен, программа сообщает об ошибке и сохраняет текущий выход. Громкость и mute не меняются.

Следующий трек работает через медиаклавишу Windows, без индикатора громкости. Требуется плеер с поддержкой медиаклавиш. При активном RDP обработка зависит от настроек сеанса и плеера.

Существующие команды Favorite1, Favorite2, VolumeUp, VolumeDown и команды совместимости для старых назначений колеса сохранены. В архиве `LocalAudioControl-LegacyCommands.zip` находятся команды совместимости; они также включены в установщик. Программа не редактирует внутреннюю базу Logitech.

## Проверки и ограничения

Пройдены автоматические проверки настроек и интерфейса, выбора цели переключения, неверных настроек, последовательности повторных команд через отдельный IPC-канал, нажатия/отпускания медиаклавиши и ошибок отправки. Реальное воспроизведение автоматическими тестами не затрагивалось.

На текущем компьютере выполнены четыре реальные команды переключения двух избранных: Console/Multimedia менялись ожидаемо, Communications сохранился. Исходные выходы восстановлены.

Физические кнопки, следующий трек в плеере, запуск новых команд при закрытой программе и работа при активном RDP требуют ручной проверки. Windows 10/11, .NET Framework 4.8 или новее; установщик не подписан цифровой подписью. Контрольные суммы — в `SHA256SUMS.txt`.
