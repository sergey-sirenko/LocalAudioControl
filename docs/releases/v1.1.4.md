# Local Audio Control v1.1.4

Исправлено выключение звука при нулевой громкости и его возврат при увеличении, включая управление колесом Logitech.

- При 0% включается mute. Любое увеличение громкости снимает mute.
- После записи проверяются фактические громкость и mute. Если устройство изменило одно из значений, программа повторяет запись, максимум пять попыток. Неподтверждённое состояние сообщает как ошибку.
- Добавлены команды совместимости для старых назначений колеса: `Local-Volume-Up.exe` и `Local-Volume-Down.exe`. Они передают команды установленной Local Audio Control вместо самостоятельного изменения громкости.

## Установка и старые назначения Logitech

Запустить `LocalAudioControl-Setup.exe`. Избранные устройства, цвета, шаг и другие настройки сохраняются.

Если колесо уже назначено на `Commands/VolumeUp.exe` и `VolumeDown.exe` новой программы, перенастройка не требуется.

Если колесо вызывает старые `C:\Tools\LocalAudio\Local-Volume-Up.exe` и `Local-Volume-Down.exe`, сохранить резервные копии этих двух файлов и заменить их одноимёнными файлами из архива `LocalAudioControl-LegacyCommands.zip` либо папки `LegacyCommands` рядом с установленной программой. После этого прежние назначения будут использовать новую программу. Внутренняя база Logitech не изменяется. Для отката вернуть сохранённые EXE.

## Проверка

Пройдены автоматические проверки настроек, интерфейса и реальных аудиовыходов. На двух избранных выходах проверена последовательность уровней с отложенным чтением состояния. Исходные устройства, громкость и mute восстановлены в `finally`.

На текущем компьютере проверены установленные команды и старые пути Logitech: уменьшение до 0% с mute и увеличение до 3% без mute. Физическое колесо после замены старых EXE ещё требует подтверждения пользователем.

Windows 10/11, .NET Framework 4.8 или новее. Фактическая проверка выполнена на Windows 11; Windows 10 и x86 отдельно не проверялись. Установщик не подписан цифровой подписью. Контрольные суммы файлов находятся в `SHA256SUMS.txt`.
