# v1.1.7 — следующий трек при RDP

[Изменения, установка, проверки и ограничения v1.1.7](releases/v1.1.7.md).

`NextTrack.exe` теперь сначала переключает текущую локальную SMTC-сессию Windows, а не отправляет медиаклавишу в активное окно. Поэтому при полноэкранном RDP трек меняется в локальной Яндекс.Музыке (Chrome), а не в удалённом сеансе. Если SMTC-сессии нет или плеер не поддерживает «следующий», используется прежняя медиаклавиша.

Проверено на реальной сессии Chrome и в полноэкранном RDP; исправление 1.1.6 с подсказками клавиш сохранено.

# v1.1.6 — фокус после кнопок мыши

[Изменения, установка, проверки и ограничения v1.1.6](releases/v1.1.6.md).

После команд с кнопки или колеса мыши (громкость, избранное, переключение выхода, следующий трек) программа проверяет через UI Automation, не остался ли фокус на строке меню активного окна, и при необходимости отправляет `Esc`. Это убирает подсказки клавиш в Notepad, WordPad и Word и возвращает ввод в текст. Окно не активируется заново, модификаторы не отпускаются, буфер обмена не используется.

Причина подтверждена диагностикой: активным всё время оставался Notepad, а UIA в момент команды показывал `MenuItem/Microsoft.UI.Xaml.Controls.MenuBarItem`, тогда как в норме — `Document/RichEditD2DPT`.

# v1.1.5 — две боковые кнопки мыши

[Изменения, установка, проверки и ограничения v1.1.5](releases/v1.1.5.md).

Добавлены `ToggleOutput.exe` (`--toggle-output`) для переключения двух избранных выходов одной кнопкой и `NextTrack.exe` (`--next-track`) для следующего трека через стандартную медиаклавишу Windows. Оба файла устанавливаются в `Commands`; переднюю и заднюю кнопки назначить через «Открыть приложение» в Logitech Options+.

Переключение использует актуальный выход Windows. Если активен первый избранный — выбирается второй; иначе — первый. Требуются два разных настроенных избранных, недоступный целевой выход вызывает уведомление. Существующие назначения, настройки и команды совместимости сохраняются. Медиакоманда не вызывает индикатор громкости.

Пройдены автоматические проверки выбора цели, неверных настроек, последовательности повторных команд через отдельный IPC-канал, структуры нажатия/отпускания медиаклавиши и ошибок отправки без управления реальным плеером, а также существующие проверки настроек и интерфейса. Приложение и установщик 1.1.5 собраны. На текущем компьютере выполнены четыре реальные команды переключения: Console/Multimedia менялись ожидаемо, Communications сохранился, исходные выходы восстановлены в `finally`. Физические кнопки, следующий трек в плеере, запуск новых команд при закрытой программе и работа при активном RDP требуют ручной проверки.

# v1.1.1 — Local Audio Control

Первый опубликованный релиз устанавливаемого приложения управления локальным звуком Windows.

## Возможности

- Выбор доступного устройства воспроизведения и двух избранных с собственными названиями.
- Регулировка громкости 0–100%, настраиваемый шаг (по умолчанию 3%) и mute.
- Значок в трее с процентом и отдельным цветом каждого избранного устройства.
- Автоматический контраст цифр и отображение выключенного звука.
- Индикатор названия устройства и уровня, не забирающий фокус у RDP.
- Команды Favorite1, Favorite2, VolumeUp и VolumeDown для кнопок мыши.
- Автозапуск, настройки пользователя и установщик без повышения прав.

В версии 1.1.1 исправлено перекрытие кнопок выбора цвета полями названия. Добавлены переход «Громкость…» из настроек и кнопки «Тише»/«Громче».

## Проверки

Проверены переключение двух аудиовыходов, громкость, mute, границы диапазона, последовательная обработка параллельных команд, отказ для недоступного ID, установка, обновление и удаление с сохранением настроек. Работа всех четырёх команд при активном RDP подтверждена пользователем. Проверены миграция настроек без цветов и отрисовка интерфейса при моделировании масштабов 100/150/200%.

## Требования и ограничения

- Windows 10/11 и .NET Framework 4.8 или новее.
- Фактическая проверка выполнялась на Windows 11 build 26200 с .NET Framework 4.8.1; отдельная Windows 10 и x86 не проверялись.
- Моделирование DPI не заменяет проверку перемещения окна между мониторами с разным DPI. Физическое переподключение USB и принудительный перезапуск Проводника отдельно не проверялись.
- Установщик не подписан цифровой подписью. Дополнительные компоненты автоматически не скачиваются.
- Изменяются роли Console и Multimedia; Communications и микрофоны сохраняются.

Скачать `LocalAudioControl-Setup.exe` из файлов релиза. Контрольная сумма находится в `LocalAudioControl-Setup.exe.sha256`.
