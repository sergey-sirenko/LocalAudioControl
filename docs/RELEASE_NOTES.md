# v1.1.1 — Local Audio Control

Первый опубликованный релиз устанавливаемого приложения управления локальным звуком Windows.

## Возможности

- Выбор доступного устройства воспроизведения и двух избранных с собственными названиями.
- Регулировка громкости 0–100%, настраиваемый шаг (по умолчанию 3%) и mute.
- Значок в трее с процентом и отдельным цветом каждого избранного устройства.
- Автоматический контраст цифр и отображение выключенного звука.
- Индикатор названия устройства и уровня, не забирающий фокус у RDP.
- Команды Favorite1, Favorite2, VolumeUp и VolumeDown для кнопок мыши.
- Автозапуск, настройки пользователя и установщик без повышения прав.

В версии 1.1.1 исправлено перекрытие кнопок выбора цвета полями названия. Добавлены переход «Громкость…» из настроек и кнопки «Тише»/«Громче».

## Проверки

Проверены переключение двух аудиовыходов, громкость, mute, границы диапазона, последовательная обработка параллельных команд, отказ для недоступного ID, установка, обновление и удаление с сохранением настроек. Работа всех четырёх команд при активном RDP подтверждена пользователем. Проверены миграция настроек без цветов и отрисовка интерфейса при моделировании масштабов 100/150/200%.

## Требования и ограничения

- Windows 10/11 и .NET Framework 4.8 или новее.
- Фактическая проверка выполнялась на Windows 11 build 26200 с .NET Framework 4.8.1; отдельная Windows 10 и x86 не проверялись.
- Моделирование DPI не заменяет проверку перемещения окна между мониторами с разным DPI. Физическое переподключение USB и принудительный перезапуск Проводника отдельно не проверялись.
- Установщик не подписан цифровой подписью. Дополнительные компоненты автоматически не скачиваются.
- Изменяются роли Console и Multimedia; Communications и микрофоны сохраняются.

Скачать `LocalAudioControl-Setup.exe` из файлов релиза. Контрольная сумма находится в `LocalAudioControl-Setup.exe.sha256`.
