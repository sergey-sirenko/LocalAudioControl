# Local Audio Control

Программа для Windows 10/11: выбор устройства воспроизведения, регулировка громкости, цветной значок с процентом в трее и всплывающий индикатор. Прямое управление Windows Core Audio позволяет регулировать локальный звук при активном RDP.

## Установка и возможности

Скачать `LocalAudioControl-Setup.exe` из файлов релиза. Установка для текущего пользователя без прав администратора. Требуется .NET Framework 4.8 или новее; приложение работает без интернета, Audio Switcher и службы Windows. Установщик не подписан цифровой подписью.

При первом запуске выбрать два избранных устройства. Начальные параметры: шаг 3%, индикатор 1,2 секунды, автозапуск включён. ID устройств конкретного компьютера в программу не зашиты.

- Все доступные устройства воспроизведения и два избранных с собственными названиями.
- Ползунок громкости, кнопки «Тише»/«Громче» и выключение звука.
- Процент на значке в трее, название устройства и mute в подсказке.
- Отдельный цвет каждого избранного и автоматический контраст цифр.
- Индикатор поверх окон без перехвата фокуса и щелчков.
- Шесть EXE-команд для кнопок и колеса мыши, включая переключение избранных одной кнопкой и следующий трек.
- Автозапуск, сохранение настроек при обновлении и штатное удаление.

Левый щелчок по значку открывает управление звуком, правый — меню настроек и выхода. После «Выхода» запускать через меню «Пуск» → Local Audio Control.

При установке 0% дополнительно включается выключение звука устройства. Любое увеличение громкости возвращает звук. Уменьшение ненулевой громкости сохраняет mute.

## Сборка из этой папки

```powershell
powershell -NoProfile -File .\apps\LocalAudioControl\build.ps1
powershell -NoProfile -File .\apps\LocalAudioControl\test.ps1
```

Используются .NET Framework 4.8 и Inno Setup 6. Установщик создаётся в `dist`. Для сборки только приложения использовать `build.ps1 -AppOnly`.

Результаты сборки не хранятся в Git; установщик публикуется в релизе вместе с контрольной суммой SHA-256.

Микрофоны и устройство связи (Communications) не меняются. При отключении избранного устройства программа сообщает об ошибке вместо выбора другого выхода. Приложение не редактирует внутреннюю базу настроек Logitech.
