# Local Audio Control 1.1.1

Приложение для Windows 10/11 и .NET Framework 4.8. Управляет локальным звуком из трея, окна программы и четырёх команд для кнопок мыши. Работает без сети, Audio Switcher и службы Windows.

## Установка и использование

Запустить `dist/LocalAudioControl-Setup.exe` из корня репозитория. Установка выполняется для текущего пользователя в `%LOCALAPPDATA%\Programs\LocalAudioControl`, без запроса прав администратора. Установщик проверяет .NET Framework 4.8 и ничего не скачивает. Программа и установщик не имеют цифровой подписи.

При первом запуске открыть настройки и выбрать два избранных выхода. Названия, шаг громкости (по умолчанию 3%), индикатор (1,2 секунды) и автозапуск настраиваются в этом же окне. На другом компьютере исходных ID устройств нет — их нужно выбрать из его списка. Смена избранных в настройках не переключает звук до команды пользователя.

Рядом с названием каждого избранного есть кнопка «Цвет…». Выбрать цвет в стандартной палитре Windows и нажать «Сохранить»: фон значка сразу изменится для активного устройства. При переключении цвет следует за выбранным избранным. По умолчанию первое избранное синее, второе зелёное; остальные выходы синие. Цифры автоматически чёрные или белые для контраста, при mute цвет сохраняется и число перечёркивается. Настройки 1.0 без цветов совместимы: применяются эти начальные цвета, остальные параметры сохраняются.

- На значке в трее — число громкости; при наведении — название устройства, процент и mute. При mute число перечёркнуто. Значок может быть скрыт под стрелкой Windows: его можно переместить в видимую область средствами панели задач.
- Левый щелчок открывает выбор выхода, ползунок 0–100% и выключение звука; правый — меню настроек и выхода.
- Из настроек перейти к регулировке можно кнопкой «Громкость…». В окне управления также есть кнопки «Тише» и «Громче» с заданным шагом.
- Изменения из Windows и других программ отражаются опросом Core Audio каждые 300 мс; список устройств обновляется каждые 1,5 секунды. Это не требует фоновых хуков клавиатуры.
- Индикатор выводится после команды переключения/громкости/mute. Не активирует окно и пропускает мышь, в том числе поверх RDP. Внешние изменения обновляют трей, не вызывая вторую всплывающую панель.
- Выбираются Console и Multimedia. Микрофоны, Communications и громкость других выходов не изменяются. При регулировке mute автоматически не снимается.

После команды «Выход» запустить приложение заново через меню «Пуск» → Local Audio Control (либо найти его по названию в поиске Windows). Другой способ — Win+R: `"%LOCALAPPDATA%\Programs\LocalAudioControl\LocalAudioControl.exe"`. Закрытие окна настроек крестиком оставляет приложение в трее; команда «Выход» завершает его полностью.

## Logitech Options+

Кнопка «Команды для мыши» в настройках открывает папку `Commands` внутри установленной программы. Через действие «Открыть приложение» назначить:

| Действие | EXE |
| --- | --- |
| Первое избранное (например, наушники) | `Favorite1.exe` |
| Второе избранное (например, ЦАП) | `Favorite2.exe` |
| Колесо: громкость вверх | `VolumeUp.exe` |
| Колесо: громкость вниз | `VolumeDown.exe` |

При наличии отдельного профиля RDP назначения должны быть заданы и в нём. В существующем двухстороннем назначении колеса заменить пути команд каждого направления. Внутреннюю БД Logitech установщик и программа не редактируют. При отсутствии работающего экземпляра EXE-команда запускает приложение в трее.

## Настройки и восстановление

Настройки: `%LOCALAPPDATA%\LocalAudioControl\settings.json`; предыдущая сохранённая версия — `settings.json.bak`. Запись выполняется через временный файл и атомарную замену. При повреждённом JSON приложение не затирает исходник, а сообщает ошибку. Журнал — `error.log` в том же каталоге.

Избранное устройство хранится по ID Windows. Если оно отключено или драйвер изменил ID, команда выдаёт уведомление, не переключая звук на другой выход. Подключить устройство либо заново выбрать его в настройках. Не используются имена/ID FiiO или других устройств, зашитые в код.

Автозапуск: пользовательский ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `LocalAudioControl`. Отключается в настройках и удаляется при деинсталляции. Обновление сохраняет настройки; интерактивное удаление предлагает сохранить или удалить их. Тихое удаление сохраняет настройки.

Ранее работавшие EXE в `C:\Tools\LocalAudio` не заменяются и не удаляются. Для отката назначить их кнопкам Logitech, затем выйти из новой программы/удалить её.

## Сборка

Основной способ — `powershell -NoProfile -File .\apps\LocalAudioControl\build.ps1`. Используется штатный компилятор .NET Framework; зависимости NuGet и .NET SDK не нужны. Для установщика нужен [Inno Setup 6](https://jrsoftware.org/isdl.php); можно передать `-IsccPath C:\...\ISCC.exe`. `-AppOnly` собирает приложение и команды без установщика. `LocalAudioControl.csproj` предназначен для открытия в IDE с установленными reference assemblies .NET Framework 4.8.

Результат: `dist/LocalAudioControl-Setup.exe`. Папка `build` содержит EXE приложения, конфигурацию и команды; папка `dist` и результаты сборки исключены из Git. Сборка повторяется скриптом; побайтовая идентичность бинарников штатным старым компилятором не гарантируется.

Исходники разделены на Core Audio, пользовательские настройки, UI, IPC и команды. Доступ к именованному каналу разрешён только текущему SID пользователя, сетевые токены запрещены; имя канала и mutex содержит ID сеанса. Повторный запуск передаёт команду существующему экземпляру.

CLI основного EXE: `--tray`, `--settings`, `--panel`, `--favorite1`, `--favorite2`, `--volume-up`, `--volume-down`, `--toggle-mute`, `--volume=0..100`, `--mute=true|false`, `--quit`. Для диагностики `--status-file "путь.json"` сохраняет JSON состояния; без запущенного экземпляра эта команда читает состояние без запуска трея и записи настроек. Ответ включает `ok`; код завершения команды 0 — успех, 1 — ошибка. Отсутствие избранного сопровождается уведомлением с предложением выбрать его в настройках.

## Проверки

`test.ps1` проверяет исходные значения и валидацию, отказ для несуществующего выхода без переключения и создаёт изображения окон/значков в `build/qa`. Масштаб 100/150/200% моделируется геометрией и шрифтами без изменения настроек монитора. Это не заменяет проверку настоящего переключения DPI между мониторами.

`test.ps1 -AudioIntegration` дополнительно меняет реальные выходы, уровень и mute. Требует настроенных избранных и спокойного момента без параллельной регулировки. После проверки восстанавливает состояния устройств и исходные роли Console/Multimedia в `finally`.

История версии, выполненные проверки и ограничения описаны в [заметках к релизу](../../docs/RELEASE_NOTES.md).

Для прежних назначений колеса сборка также создаёт `build/LegacyCommands/Local-Volume-Up.exe` и `Local-Volume-Down.exe`. Установщик помещает их в папку `LegacyCommands` рядом с программой; они также доступны в архиве релиза `LocalAudioControl-LegacyCommands.zip`. Это переадресация команд установленной программе из профиля текущего пользователя. При ручной замене старых EXE сначала сохранить их копии. Установщик не размещает эти файлы в старом каталоге автоматически.
